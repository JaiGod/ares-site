# Project ARES · website

Live site: **https://jaigod.github.io/ares-site/**

This is the public website for the NASA HUNCH **Lunar Smart Adaptive Habitat** (Project ARES), with all three simulators playable in the browser:

| | Game | Engine | Play |
|---|---|---|---|
| SIM-01 | Lunar Smart Adaptive Habitat (realistic) | Unity 6 · VR + desktop | [play/](https://jaigod.github.io/ares-site/play/) |
| SIM-02 | Lunar Habitat Commander (sci-fi) | Unity 6 · VR + desktop + mobile | [play2/](https://jaigod.github.io/ares-site/play2/) |
| SIM-03 | Crew Health Sim | Godot 4 · desktop + web | [godot/](https://jaigod.github.io/ares-site/godot/) |

This repo only holds the web build. The source code, Blender files, STLs and papers are in [JaiGod/LunarSmartAdaptiveHabitat](https://github.com/JaiGod/LunarSmartAdaptiveHabitat). The main repo grew past GitHub Pages' 1 GB limit, so the website is published from here.
